# KilnPolish

Syncs containerized development environments with shared config files and version control integration.

The key benefits of using KilnPolish include:

- Syncs containerized development environments with
- shared config files and version
- control integration

## Key Features

- Syncs containerized development environments with
- shared config files and version
- control integration

## Technology Stack

- typescript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/KilnPolish.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

KilnPolish is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
